# Visuels de Progressive Medals

`platinum.png`, `emerald.png` et `diamond.png` sont les PNG fournis par chakymi.
La fenêtre Openplanet les affiche dans cet ordre : Platine, Émeraude, Diamant.
L'interface facultative IMedal d'Ultimate Medals Extended expose des icônes texte, pas ces textures PNG ; elle utilise donc un cercle de remplacement.
